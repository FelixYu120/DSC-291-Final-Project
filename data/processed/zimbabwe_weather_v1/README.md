# Zimbabwe labels with NASA POWER weather

All 6,598 screened labels retain their original outcomes and metadata, with 46 weather predictors.
Use the existing comparison eligibility and protected splits; the full catalog is not a training split.
NASA POWER monthly PRECTOTCORR is mm/day, multiplied by actual month length; T2M is degrees C.
A 0.5 × 0.625 degree grid centre is assigned to each point. These are regional reanalysis estimates.
Normals are 1991–2020; each label uses October of the prior year through June of its year.
See docs/ZIMBABWE_WEATHER_PROTOCOL.md for exact methods and source links, and the ledger for every URL.
Raw response and request metadata paths/hashes are in the manifest. No target labels are imputed.
